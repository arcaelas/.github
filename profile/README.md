# Arcaelas Insiders, LLC

We build mobile apps, games and web platforms, and we maintain the open source TypeScript libraries they run on.

### Apps on Google Play

- [Arko Studio](https://play.google.com/store/apps/details?id=com.arcaelas.ai): AI agents with their own instructions, tools and memories.
- [Bolsillito](https://play.google.com/store/apps/details?id=com.arcaelas.bolsillito): personal finances that never leave your phone.
- [ChessAI](https://play.google.com/store/apps/details?id=com.arcaelas.chess): chess against an engine that runs on the device.
- [La arepera: Sabor de la casa](https://play.google.com/store/apps/details?id=com.arcaelas.arepera): Venezuelan idle arcade.
- [Minicraft: Alessandro](https://play.google.com/store/apps/details?id=com.arcaelas.bloques): voxel sandbox with online worlds.
- [Valhalla](https://play.google.com/store/apps/details?id=com.arcaelas.valhalla): Viking strategy.
- [Runway: Squad vs Zombies](https://play.google.com/store/apps/details?id=com.arcaelas.runway): squad shooter.
- [Palabreos](https://play.google.com/store/apps/details?id=com.arcaelas.worders): Spanish word game.
- [Dominó: El Venezolano](https://play.google.com/store/apps/details?id=com.arcaelas.domino): Venezuelan dominoes against the computer or on the local network.

### Libraries

- [@arcaelas/utils](https://github.com/arcaelas/utils): dependency-free helpers for TypeScript and JavaScript.
- [@arcaelas/dynamite](https://github.com/arcaelas/dynamite): decorator-first ORM for DynamoDB.
- [@arcaelas/agent](https://github.com/arcaelas/agent): AI agents with tools over OpenAI, Claude, Groq, DeepSeek and Ollama.
- [@arcaelas/whatsapp](https://github.com/arcaelas/whatsapp): WhatsApp Web client for Node.
